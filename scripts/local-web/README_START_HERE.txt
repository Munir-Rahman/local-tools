ToolNest - offline local website (Windows / Mac / Linux)

You must EXTRACT this complete GitHub Actions ZIP. Do not double-click index.html.

Windows: Double-click START_TOOLNEST_WINDOWS.bat
macOS/Linux: In a terminal in this folder: python3 run_toolnest.py
Browser address: http://127.0.0.1:8765/

Python 3 is required, but you do not need pip, Node, npm, Flask or Django.
Keep the Python terminal running while working with ToolNest.
No Internet is needed after downloading for supported local tools.
The server binds to 127.0.0.1, so it is not exposed to your network.
Keep using port 8765 to retain browser-origin local data.
Please back up drafts before clearing the browser's site data.
This artifact is a website, NOT a desktop installer or Android/iOS app.
